💾 GitHub Save & Sync

Your music changes are saved instantly in your browser! To host them permanently on GitHub Pages, pick an option below:

🚀 Option 1: 1-Click Sync to GitHub (Automatic)
Enter your GitHub Personal Access Token once. Whenever you click Sync to GitHub, it commits music.json directly to your repository!
📥 Option 2: Download & Git Push (Manual)
Download the updated music.json file, place it in your project folder, and push to GitHub.
