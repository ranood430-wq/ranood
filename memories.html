💾 GitHub Save & Sync

Your memories and modifications are saved instantly right here in your browser! To host them permanently on GitHub so anyone visiting the link sees them, use one of the two easy options below:

🚀 Option 1: 1-Click Sync to GitHub (Automatic)
Enter your GitHub Personal Access Token once. Whenever you click Sync to GitHub, it will automatically commit memories.json straight to your repository! GitHub Pages updates automatically within 1-2 minutes.
📥 Option 2: Download & Git Push (Manual)
Download the updated memories.json file with all your folders and photos, place it in your project folder, and push to GitHub.
